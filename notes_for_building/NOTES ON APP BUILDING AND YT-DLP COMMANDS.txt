HOW TO RUN YT-DL ON PROD SERVER 
------------------------------------------------------------
1. In order to get this to work  Ron a server you have to be logged in and pass in the cookies to yt-dlp_linux 
2. To get the cookie, run this command locally 
	yt-dlp_macos --write-auto-sub --skip-download --sub-lang en --cookies-from-browser chrome --cookies /Users/stan.lee/Documents/go/council/cookies.txt --convert-subs srt "https://www.youtube.com/watch?v=Vo8OBoIpXUU"
3. That will download the cookies.txt to the local app folder 
4. Now scp the cookies.txt to the server 
	scp -i /Users/stan.lee/Documents/go/cybertron.pem /Users/stan.lee/Documents/go/council/cookies.txt ec2-user@54.193.150.151:/home/ec2-user
5. Now run this command on the server. It tells --cookies to look for the uploaded cookies.txt and uses the logged in cookie to get the srt subtitle file 
	yt-dlp_linux --write-auto-sub --skip-download --sub-lang en --cookies-from-browser --cookies /Users/stan.lee/Documents/go/council/cookies.txt --convert-subs srt "https://www.youtube.com/watch?v=Vo8OBoIpXUU"
